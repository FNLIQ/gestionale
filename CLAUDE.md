# Gestionale Nastro Liquori — regole di lavoro

## Caricamento su GitHub
- Prima di ogni commit/push, chiedere gentilmente la conferma a Francesco,
  spiegando in breve cosa è stato modificato.
- Caricare (commit + push) solo dopo il suo esplicito "sì". Mai in automatico.

## Modifiche al codice
- Non rompere niente nella logica: per gli interventi grafici modificare solo il CSS,
  lasciando invariati HTML e JavaScript, salvo richiesta esplicita.
